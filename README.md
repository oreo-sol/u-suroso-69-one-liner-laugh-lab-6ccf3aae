One short funny line answering a prompt: the excuse a robot vacuum gives after eating a sock.

Entry: "In my defense, I thought it was a small rug with ambitions."

`main.ts` writes the line to `/output/entry.txt`. Run with Node 22+:

```sh
node main.ts
```
